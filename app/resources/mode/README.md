# Fluxxwave 모드

Windows를 다시 설치하지 않고, 쓰던 PC 그대로 백그라운드 활동을 줄이는 설정 7가지를 한 번에 켜고 끄는 스위치입니다. 켤 때 원래 값을 기록해 두었다가 끌 때 그 값으로 되돌립니다. 설치하거나 지우는 프로그램은 없습니다.

## 사용법

1. `Fluxxwave Mode.cmd`와 `Set-FluxxwaveMode.ps1`을 같은 폴더에 둡니다.
2. `Fluxxwave Mode.cmd`를 더블클릭합니다. "관리자 권한으로 실행"으로 열지 마세요. 사용자 설정은 본인 계정에서 바꿔야 합니다.
3. `1`은 켜기, `2`는 끄기, `3`은 닫기입니다.
4. 시스템 설정을 바꿀 때 Windows가 관리자 권한을 한 번 묻습니다. 거절하면 사용자 설정만 바뀌고 "일부만 켜져 있습니다"로 표시됩니다.

PC를 다시 시작할 필요는 없습니다.

## 켜면 바뀌는 것

| 설정 | 켜면 | 감수할 점 |
| --- | --- | --- |
| 백그라운드 앱 (2개) | Microsoft Store 앱이 백그라운드에서 실행되지 않습니다. | 메일·일정 같은 Store 앱의 알림이 늦거나 오지 않을 수 있습니다. |
| 게임 DVR, 게임 캡처 (2개) | 게임 화면을 백그라운드에서 녹화하지 않습니다. | Game Bar로 게임 화면을 녹화하거나 캡처할 수 없습니다. |
| 전송 최적화 | 업데이트를 Microsoft에서만 받고 다른 PC와 주고받지 않습니다. | 업데이트는 그대로 받습니다. 설정 앱의 전송 최적화 화면에 "조직에서 관리" 문구가 보입니다. |
| 검색 색인 서비스 | Windows Search 서비스를 멈추고 다시 시작되지 않게 합니다. | 시작 메뉴와 탐색기의 파일 검색이 느려지고, Outlook 검색이 제한됩니다. |
| 전원 관리 옵션 | 쓰고 있는 옵션이 "균형 조정"이나 "절전"이고 PC에 "고성능"이 있으면 그것으로 바꿉니다. 직접 고르거나 만든 다른 옵션은 그대로 두고 건너뜁니다. | 전력 소모와 발열이 늘어납니다. 노트북은 배터리가 더 빨리 닳습니다. |

보안 기능(Windows 보안, 방화벽, SmartScreen, 사용자 계정 컨트롤)은 건드리지 않습니다.

체감 효과는 크지 않습니다. 백그라운드에서 도는 일을 줄여 주는 정도이고, 게임 프레임이 눈에 띄게 오르는 설정은 아닙니다. Windows를 새로 설치해서 쓰는 Fluxxwave 전체 구성의 일부만 옮긴 것입니다.

## 끄면

켜기 직전의 상태를 아래 파일에 기록해 두고, 끌 때 그대로 되돌린 뒤 기록을 지웁니다. 기록하는 내용은 레지스트리 값이 있었는지와 그 종류·데이터, 서비스의 시작 유형과 실행 여부, 쓰고 있던 전원 관리 옵션입니다.

- 사용자 설정: `%LOCALAPPDATA%\Fluxxwave\Mode\user.json`
- 시스템 설정: `%ProgramData%\Fluxxwave\Mode\machine.json`

모드가 켜진 동안 같은 설정을 직접 바꿨더라도, 끄면 켜기 전 값으로 돌아갑니다. 되돌리지 못한 설정은 기록에 남겨 두므로 끄기를 다시 실행하면 됩니다.

## 명령줄에서

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Set-FluxxwaveMode.ps1 -State On
```

`-State`에는 `On`, `Off`, `Status`, `Menu`를 쓸 수 있습니다. 종료 코드는 `0` 완료, `2` 바꾸거나 되돌리지 못한 설정이 있음, `3` 관리자 권한이 승인되지 않음입니다.

## 시험

`tests/Fluxxwave.Mode.Tests.ps1`이 GitHub Actions의 Windows 가상 머신에서 실제 설정 7개를 켰다가 끄고, 켜기 전과 완전히 같은지 확인합니다. 그 밖의 시험은 시험 전용 레지스트리 키만 씁니다. 개발자 PC에서는 실제 설정을 바꾸는 시험이 실행되지 않습니다.
